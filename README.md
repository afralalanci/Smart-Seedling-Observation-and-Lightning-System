# Smart-Seedling-Observation-and-Lightning-System
SMART SEEEDLING OBSERVATION AND LIGHTNING SYSTEM
Afra LALANCI
Department of Electronics and Communication Engineering
Supervisor: Asst. Prof. Ramazan DAŞBAŞI

In this project, an intelligent farming system was designed based on a unique agricultural practice, the seedling method. This method involves initiating seeds within pre-prepared seedlings, providing a controlled and efficient growth environment to support faster plant growth, early harvesting, and healthy development. However, to meet the demands of modern agriculture, closer monitoring of environmental factors and notification to the farmer are essential. The developed smart farming system adopts an environmental control and image processing-based approach. Images collected through cameras are analyzed using an image processing library to determine plant growth stages, which are then recorded. The system periodically measures various environmental factors such as temperature, humidity, and light levels, providing the farmer with notifications if values exceed or fall below predefined thresholds, enabling timely intervention. The project includes a user interface and a web-based control panel, offering farmers the ability to monitor live images and track sensor data. This allows farmers to engage in more informed and effective agricultural management. Furthermore, the modular design of the project facilitates the easy integration of different sensors and technological advancements, providing flexibility for future expansion according to evolving needs. This study presents an original solution that strengthens the seedling method in the agricultural sector and provides farmers with a more effective agricultural management by integrating modern
technology. Serving as an example of how smart farming applications can be integrated into the agricultural industry, it significantly contributes to the future sustainability of agriculture
Keywords: Smart farming, seedling method, image processing, agricultural optimization, sensor integration, user interface, sustainability, efficiency
